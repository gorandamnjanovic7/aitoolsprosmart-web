V8 DE-BRANDING IMAGE DNA ENGINE
PROFESSIONAL TECHNICAL MANIFEST V2.0
============================================================

This document describes the technical structure, workflow, and commercial value of the provided Python script.

The script analyzes a reference image and extracts a clean, de-branded cinematic JSON blueprint. Its purpose is to help users recreate the visual style of a branded or logo-heavy image while explicitly removing brand identifiers, logos, text, markers, and commercial branding from the generated prompt structure.

------------------------------------------------------------
💎 1. V8 De-Branding Visual DNA Extraction
------------------------------------------------------------

The script takes one image as input and returns a strict JSON description of the image.

The key difference from a normal image analyzer is that this engine focuses on de-branding. It identifies the main object and describes it as a clean, minimalist version stripped of logos, brand names, markers, text, visible trademarks, and commercial branding elements while preserving the object’s visual structure, materials, lighting, composition, and premium cinematic identity.

💎 Technical Insight:
The script converts the input image into Base64, sends it with a specialized de-branding prompt to a vision model, receives the response, removes markdown code fences if present, and returns clean JSON output for a Node.js server or another backend workflow.

------------------------------------------------------------
💎 2. Clean Minimalist Object Reconstruction
------------------------------------------------------------

The core instruction tells the model to identify the main object and describe it as a clean, minimalist version.

This is useful for watches, luxury items, fashion products, product packaging, cars, electronics, jewelry, accessories, premium objects, and branded commercial visuals.

💎 Commercial Value:
Many AI marketplaces, contributor platforms, and creative workflows need unbranded outputs. This engine helps transform a visual reference into brand-safe creative data while keeping the premium look.

------------------------------------------------------------
💎 3. Explicit No-Brand / No-Logo / No-Text Lock
------------------------------------------------------------

The script forces the JSON subject field to include this direction:

clean, minimalist design, stripped of all brand logos, markers, and text

💎 Why this matters:
A weak prompt might accidentally recreate visible logos or trademark-like markings. This script places the de-branding instruction directly into the subject description, making the final JSON safer for clean AI image generation.

------------------------------------------------------------
💎 4. Base64 Image Encoding
------------------------------------------------------------

The script reads the local image file and converts it into Base64 format.

💎 Technical Insight:
The function encode_image(image_path) opens the image in binary mode and returns a Base64 string. This allows the image to be embedded directly into the OpenAI API request as a data URL.

💎 Practical Benefit:
No external file hosting is required. The local image can be sent directly to the API request.

------------------------------------------------------------
💎 5. OpenAI Chat Completions API Request
------------------------------------------------------------

The script sends the image and prompt to model gpt-4o using a direct HTTPS request with the requests library.

💎 Technical Insight:
Instead of using the OpenAI Python SDK, this version manually builds the headers and JSON payload, then calls the OpenAI API endpoint through requests.post. This gives the script a backend-friendly structure for Node.js integrations, server routes, and custom hosting flows.

------------------------------------------------------------
💎 6. Flexible API Key Loading
------------------------------------------------------------

The script checks two environment variables:

💎 VISION_API_KEY
💎 OPENAI_API_KEY

If VISION_API_KEY exists, it uses that first. If not, it falls back to OPENAI_API_KEY.

💎 Commercial Value:
This makes the engine easier to integrate into a real backend or paid tool without hardcoding sensitive credentials.

------------------------------------------------------------
💎 7. Missing API Key Protection
------------------------------------------------------------

If no API key exists, the script returns a JSON error:

{"error": "API Key is missing from Server Environment Variables."}

💎 Technical Insight:
Instead of crashing silently, the script returns a structured error response. This is useful for Node.js servers, frontend apps, and SaaS workflows because the calling system can detect the error and display a proper message.

------------------------------------------------------------
💎 8. UTF-8 Output Forced for Node.js Communication
------------------------------------------------------------

The script forces stdout to use UTF-8 encoding.

💎 Technical Insight:
sys.stdout is wrapped with io.TextIOWrapper using UTF-8. This helps prevent encoding issues when the Python script is called from a Node.js backend, especially when the output contains Serbian text, special characters, JSON strings, or emoji-like symbols.

------------------------------------------------------------
💎 9. Full V8 Master Prompt Preservation
------------------------------------------------------------

The script stores the full master prompt in V8_MASTER_PROMPT.

💎 Why this matters:
For commercial tools, prompt consistency matters. Keeping a stable master prompt gives the engine a repeatable creative identity and more predictable output.

💎 De-Branding Value:
This field is where the engine explicitly states that the object is stripped of logos, markers, text, and branding while preserving structural and material integrity.

Current limitations:

💎 processes one image at a time
💎 does not validate JSON after output
💎 does not retry failed API calls
💎 does not detect actual image MIME type
💎 always sends the image as data:image/jpeg
💎 does not save output to file automatically
💎 does not create TXT/CSV reports
💎 does not batch process folders
💎 max_tokens is set to 1000, which may be short for very complex images
💎 no temperature is explicitly set
💎 no timeout is defined for the HTTP request
