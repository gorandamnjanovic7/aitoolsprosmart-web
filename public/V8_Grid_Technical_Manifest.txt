# TECHNICAL MANIFEST — V8 GRID SYSTEM

**File:** `V8GridSystem.jsx`  
**Component:** `V8GridSystem`  
**Purpose:** Premium React prompt-generation page for Google Nano Banana 2 cinematic grid prompts.

---

## 1. Core Purpose

This page is a premium AI prompt generator that creates **100 unique cinematic grid prompts per generation cycle**.

The generated prompts are optimized for Google Nano Banana 2 / Pro style prompting, cinematic multi-panel image grids, commercial-safe visual generation, no-brand / no-logo / no-text output, TXT export, JSON export, selectable grid formats, and selectable aspect ratios.

---

## 2. Main Output

The engine generates:

**100 prompts per click**

Each prompt contains:

- strict grid structure instructions
- exact panel count
- panel-by-panel subject descriptions
- cinematic lighting metadata
- camera/lens styling
- negative prompt protection
- no-brand commercial-safe lock
- framing lock to prevent cropped subjects

---

## 3. Supported Grid Formats

### 2x4 Grid
8 panels. In wide formats it uses 2 rows x 4 columns. In 9:16 vertical mode it changes to 4 rows x 2 columns.

### 2x3 Grid
6 panels. In wide formats it uses 2 rows x 3 columns. In 9:16 vertical mode it changes to 3 rows x 2 columns.

### 2x2 Grid
4 panels. Standard 4-panel cinematic grid.

---

## 4. Supported Aspect Ratios

- 16:9 cinematic
- 21:9 ultrawide
- 9:16 vertical

The script dynamically adjusts rows and columns when vertical mode is selected.

---

## 5. Prompt Engine Logic

Main functions:

- `seededRandom(seed)` — deterministic pseudo-random generator.
- `pick(arr, seed)` — selects one array item using seeded randomness.
- `seededShuffle(array, seed)` — shuffles panel categories deterministically.
- `autoDescription(category, originalIndex, seed, promptIndex)` — builds cinematic panel descriptions.
- `makeSinglePrompt(...)` — builds one complete Nano Banana 2 optimized grid prompt.
- `makeVariations(options)` — generates exactly 100 prompt variations.

## 8. Negative Prompt System

When enabled, the negative prompt blocks:

- uneven grid
- asymmetric grid
- irregular borders
- mixed panel sizes
- extra rows
- wrong panel count
- 3x3 grid mistakes
- sub-grids
- picture-in-picture panels
- repeated subjects
- duplicate panels
- cropped subjects
- text
- logos
- brands
- watermarks
- UI elements
- blurry output
- plastic CGI look

## 9. Framing Lock

Every generated prompt forces:

## 16. Quota System

Each generation records usage in increments of:

**100 prompts**

When the quota is exhausted:

- engine locks
- cooldown starts
- `exhaustedAt` timestamp is saved
- user waits 30 days

After 30 days, quota resets and the engine unlocks.
